# How to Contribute to the AI Trust and Safety User Guide

We welcome your contributions to this user guide. Suggestions for additions and improvements are welcome. _What would you like to see covered?_

Ways to suggest ideas and provide feedback:
* Start a [discussion topic](https://github.com/The-AI-Alliance/trust-safety-user-guide/discussions){:target="discussions"} topic.
* Post an [issue](https://github.com/The-AI-Alliance/trust-safety-user-guide/issues){:target="issues"}.
* Submit a [pull request](https://github.com/The-AI-Alliance/trust-safety-user-guide/pulls){:target="tsug-repo"}.
* Send us [email](mailto:contact@thealliance.ai?subject=Suggestions for the Trust and Safety User Guide). This is a general email address, so be sure to mention this particular project. (The email &ldquo;subject&rdquo; should be filled in already with this information...)

Notice that every page has [{{ site.gh_edit_link_text }}]({{ site.gh_edit_repository }}/{{ page.path }}){:id="edit-this-page" target="doc_repo_page"} links, making it easy to view a page, then go straight to the source to make edits and submit a PR! This is the best way to help us fix typos and make similar small edits. The [repo's README](https://github.com/The-AI-Alliance/trust-safety-user-guide){:target="tsug-repo"} also describes our "DCO" requirements, which you should understand before submitting PRs, and it explains more details about testing the website locally, etc.
